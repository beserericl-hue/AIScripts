# Naming your supporting-evidence files so they route to the right Standard

When you drag a folder of appendix files into the **Review → Papers / Appendices**
panel, the system reads each file and suggests which **Standard** and
**sub-specification** it belongs to. You always get the final say — you can
accept or change the suggestion, and then **Approve** stamps it onto the file.

You can make the suggestion almost always correct — and usually *exact* — by how
you **name the file**. Two minutes of renaming saves a lot of re-assigning.

## The one rule that guarantees a correct match

**Start the filename with the Standard (and sub-spec, if you know it):**

| Name it like this | It routes to |
|---|---|
| `Standard 4 - HS Exit Survey 2022-2025.xlsx` | Standard 4 |
| `Std 11.a - Course Contents Curriculum Map.xlsx` | Standard 11.a |
| `4.b - Departmental Bylaws.pdf` | Standard 4.b |

Any of these forms works at the **start** of the name: `Standard 4`, `Std 4`,
`Std 4.a`, or just `4.a`. When the file names its Standard, the system routes it
with **95% confidence** to exactly that Standard/sub-spec — no guessing.

If a file supports **more than one** Standard, name it for the primary one and
add the others in the Review panel using the **"+ reference"** chips on the card.

## If you'd rather not prefix the Standard

The system will still try to match by the file's **topic**. To help it:

1. **Name the file by what it *is about*, not how it's handled.**
   - Good: `HS Alumni Education Outcomes.pdf`, `Curriculum Map - Course Contents.xlsx`
   - Avoid words that describe the *file*, not the subject — these confuse the
     match: `FINAL`, `UPDATED`, `copy 2`, `Master List`, `TO SEND TO FACULTY`,
     `Draft`, `v3`. (One real example matched a **curriculum map** to the
     *Faculty* standard purely because the name ended "…TO SEND TO FACULTY.")

2. **Spreadsheets need extra help.** A workbook of numbers has little text to
   read, so the name carries almost all the meaning. Give it a descriptive name
   **and/or** put a clear title in the first cell/sheet
   (e.g. `Program Exit Survey Results 2022–2025`).

## What you'll see now

- **Confident match** → the card pre-fills the Standard/sub-spec with a real
  confidence and a short reason ("names Standard 4", "topic match — Program
  Evaluation", or "the text and topic agree").
- **Not sure** → the card is left **Unassigned** and shows its closest guesses,
  so you pick — instead of a confident *wrong* answer. The file is already saved
  in your File Library either way; assigning it is one dropdown.

The percentage now means something: **high = trust it, low/Unassigned = please
check.** It is no longer "100%" on every card.
